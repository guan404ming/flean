# Flean Plan

## Objective

This file is the repo-level execution plan for turning the current artifact into
a sequence of publishable papers. It is not just a venue list. It should answer:

- what Flean can already defend today
- what is still missing for each paper claim
- which files carry the story
- what order to finish work in

The current intended paper sequence is:

1. `CPP`: establish Flean as a verified numerics framework with one strong
   end-to-end case study
2. `CAV`: lift the kernel story to compositional numerical pipelines and
   executable refinement
3. `MLSys`: connect the verified kernels to compiler and workload integration
